# Archive branch: sales-style pitch material

This branch exists so sales-style pitch files are not lost when they leave the working tree.

They stay here, at the paths they had on upstream `main` (`bf57f5d`, 2026-10-27):

- `pitch/ENTERPRISE_SPONSOR_KIT.md`
- `pitch/EXECUTIVE_PITCH_DECK.md`

The working line renames `pitch/` to `outreach/` and keeps the adoption template and the short one-pager. It does not keep the enterprise sponsor kit or the executive pitch deck.

Do not merge this branch into `main`. It is a holding branch. Retarget or cherry-pick from it only if a steward decides the sales material should return.
